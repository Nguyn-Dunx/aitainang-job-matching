# CV mẫu (D2) — ĐƯỜNG DẪN CHUẨN

C đặt CV ẩn danh thật vào đây (PDF/DOCX), hoặc file JSON đã parse.
Mỗi JSON cần có ít nhất: `id`, `skills`, `experience_years`, `education`, `target_industry`.

- CV thật: đã xin phép bằng văn bản (bằng chứng ở `data/consent/`), ẩn danh hoàn toàn.
- Tuyệt đối không lấy CV người lạ từ TopCV/LinkedIn/VietnamWorks.
- CV synthetic phục vụ test nằm ở `tests/fixtures/`, pilot D3 ở `data/processed/cvs_pilot/`.
